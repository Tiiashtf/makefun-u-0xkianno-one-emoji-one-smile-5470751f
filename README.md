One emoji, written by a program to `/output/entry.txt` — the single emoji
most likely to make a stranger smile:

> **😄**

A big, open grin with smiling eyes: the face of someone genuinely
pleased to see you. It needs no context, reads the same to a stranger
of any age or background, and is a deliberate pick rather than the
default gentle smile — a grin, not a nod. It carries no hearts, no
hug, no wink and no flirtation, so nothing about it reads oddly coming
from someone unknown. A flower is cheerful but not a greeting, a heart
is affection rather than a smile, and a hug asks for a closeness a
stranger has not earned. A grin asks for nothing and offers
everything: look, I am glad you are here.

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13, standard library only, no network. It writes
`/output/entry.txt` (one emoji plus a newline, 2 characters) and writes
the same bytes on every run; it clears only the contents of the output
directory, never the directory itself, and it refuses to write anything
that is not exactly one emoji within the 1–8 character gate.
